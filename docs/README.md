# About this directory

The files in this directory are only here to redirect people visiting the old
website at https://timendus.github.io/thimbleful to this repository, and to keep
hosting the old version of Thimbleful at the old location of
https://timendus.github.io/thimbleful/thimbleful.min.js.

The documentation site gets generated from the javascript files by [the Github
workflow](../.github/workflows/pages.yaml), stored in ./jsdoc and deployed along
with these files.
