# About this directory

The old `thimbleful.min.js` file in this directory is only here to keep hosting
it at the location of
https://timendus.github.io/thimbleful/thimbleful.min.js, in case there are
people still depending on this.

The documentation site gets generated from the javascript files by [the Github
workflow](../.github/workflows/pages.yaml), and deployed along with this file.
